В C# и .NET принято использовать комментарии-маркеры (`TODO`, `HACK`, `BUG`) в сочетании с обязательной ссылкой на задачу в трекере. Это позволяет не просто оставить заметку, но и гарантировать, что долг не потеряется.

### 📝 Основные маркеры в коде

В Visual Studio и JetBrains ReSharper по умолчанию распознаются следующие токены:

*   **`// TODO:`** — используется для обозначения незавершенной работы, временных решений или запланированного рефакторинга.
*   **`// BUG:`** — помечает известные ошибки, которые пока не исправлены (ReSharper подсвечивает их как Error).
*   **`// HACK:`** — указывает на костыль или неочевидное решение, которое работает, но требует переписывания.
*   **`// UNDONE:`** — альтернативный маркер для отмененных или незавершенных изменений.

### 🔗 Главное правило: Ссылка на тикет

Просто написать `// TODO: fix this` — плохая практика, так как такой код никто не найдет. Правильный подход — всегда связывать комментарий с задачей в баг-трекере (Jira, GitHub Issues, Azure DevOps).

**Плохо:**
```csharp
// TODO: обработать null, если пользователь не найден
```

**Хорошо:**
```csharp
// TODO: https://github.com/MyCompany/MyProject/issues/324
// Обработать null, если пользователь не найден
```
Такая ссылка позволяет любому разработчику или менеджеру перейти в задачу и увидеть контекст, приоритет и статус.

### 🛠 Инструменты для управления

*   **Visual Studio Task List:** Встроенный список задач автоматически собирает все `TODO` в проекте. Вы можете кликнуть по записи, чтобы перейти к коду.
*   **ReSharper (To-do Explorer):** Позволяет не только собирать задачи, но и настраивать кастомные паттерны (например, `Refactor:`) и автоматически превращать ссылки на тикеты в кликабельные ссылки.

### 💡 Культура и процесс

Технический долг, зафиксированный в коде, должен попадать в бэклог. В код-ревью часто действует правило: если ревьюер видит `TODO` без ссылки на задачу, он может отклонить пулл-реквест, пока автор не создаст тикет или не обновит комментарий. Это гарантирует, что долг будет виден продукт-менеджеру и получит приоритет.
